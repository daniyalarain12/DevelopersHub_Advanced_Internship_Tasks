# Mall Customer Segmentation

A simple machine learning project to segment mall customers based on age, income, and spending score.

## Tools Used
* Python
* Pandas & Seaborn (Data handling & Visualization)
* Scikit-Learn (StandardScaler, PCA, K-Means)

## Steps
1. **Data Preprocessing:** Handled categorical data (Gender) and standardized numerical features.
2. **Dimensionality Reduction (PCA):** Reduced data to 2 components for easy 2D visualization.
3. **Clustering (K-Means):** Grouped customers into 3 distinct clusters based on their spending and income patterns.

## How to Run
Run the `Mall Customers.ipynb` notebook sequentially to see the data visualizations, PCA transformations, and the final K-Means scatter plot.
